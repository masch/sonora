# Proposal: Geocerca configurable por Experiencia

Este cambio propone configurar de forma dinámica e individualizada (desde la entidad de Base de Datos `experience`) si un recorrido cuya ubicación es requerida para reproducir/descargar puede saltearse o no (bypassable).

Si la validación de ubicación puede saltearse, se le advertirá al usuario mediante una alerta antes de comenzar. Si no es salteable (comportamiento estricto por defecto), se bloqueará la reproducción.
